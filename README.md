Alumni Connect

About the Project

Alumni Connect is a Java-based desktop application used to manage alumni details, organize events, and maintain event registrations.

Technologies Used

- Java
- Java Swing
- MySQL
- JDBC

Features

- Admin Login
- Add, Update and Delete Alumni
- Manage Events
- Event Registration
- Search Alumni
- Dashboard and Statistics

Database

MySQL – "alumni_db"

Purpose

To make alumni information and event management easy, simple, and efficient.

Project Type

Java Mini Project
